PPT 的操作

PPT 是 6 种布局的组合，每种布局的操作略有不同：

布局长什么样能做什么
标题页大标题 + 副标题 + 章节出处无交互
要点列表编号要点逐条排列无交互
左右对比两栏对照，中间分割线无交互
时间轴横向时间线，节点带页码无交互
因果链箭头连接的「因 → 果」无交互
随堂测验题干 + 选项点选项后显形答案与解析

通用操作

翻页
点左右箭头，或按键盘 ← / →
跳页
底部缩略图条，点任意一页直接跳过去
看讲解
页面下方「讲解」可折叠区，是 AI 助教对这一页的口语化深入讲解。很多人不知道这里有内容
看出处
每页右下角有固定角标，如 Form 4 Sejarah, Bab 4.1, p.94。琥珀色表示来自超纲拓展
放大
工具栏的全屏按钮，演示时用

「讲解」这块值得点开。PPT 上的文字是精简的要点，讲解区才是把这一页讲透的口语化内容—— 相当于老师在你旁边讲。它是生成时一起产出的，不是事后补的。

导出成 PDF（打印/交作业用）

工具栏右侧有一个「导出 PDF」按钮，点它会把整份课件的全部页面导出（不是只导当前页）。

  1. 点「导出 PDF」

    会弹出系统的打印对话框。这是正常的——导出走的是浏览器打印管线，输出的是矢量 PDF，放大不会糊。

  2. 目标打印机选「另存为 PDF」

    Windows 上是 Microsoft Print to PDF 或「另存为 PDF」，macOS 是左下角的「PDF → 存储为 PDF」。

  3. ⚠️ 取消勾选「页眉和页脚」

    这一步必须做。Chrome/Edge 默认勾选它，会把网址、日期、页码直接叠在幻灯片内容上——深色封面上尤其明显，而且代码关不掉。

  4. 保存

    页面尺寸是 16:9 横向（338.7 × 190.5 mm），每页一张幻灯片，没有白边。

「背景图形」不用管。实测无论勾不勾，导出的 PDF 逐像素一致——代码里已经强制了 print-color-adjust: exact，深色背景不会丢。

目前只有 PPT 支持导出。2D 动画和 3D 场景的按钮是灰的—— 它们的「导出」语义不同（一个是动画、一个是可交互场景），打印成静态 PDF 意义不大。 如果确实需要，可以用系统截图工具截当前画面。

2D 动画的操作

2D 动画用于"随时间演变的过程"——疆域变化、航线开辟、权力转移、受力分解。

播放 / 暂停
底部时间轴的播放按钮，元素会在关键帧之间平滑补间（不是瞬移）
拖时间轴
拖动进度条到任意位置，画布实时跟随
逐帧步进
上一帧 / 下一帧按钮，精确看每一步的变化
看旁白
时间轴上方显示当前步骤的旁白解说
点元素
点击任意图形，弹出该元素的详细知识点解释
悬停看页码
鼠标停在元素上显示它对应的课本页码

为什么拖时间轴不会卡？因为动画是前端实时算的，不是服务端渲染的视频。 拖动只是改变一个数字，画面立刻重绘。这也是为什么首帧能在一秒内出来。

3D 场景的操作

3D 用于需要空间想象的内容——建筑内部结构、地形与战局、机械构造。

旋转
鼠标左键拖拽，绕场景中心旋转
缩放
滚轮，或双指捏合
平移
鼠标右键拖拽
复位
工具栏的「复位」按钮，回到初始视角
点标注点
场景里有悬浮的标注点（至少 3 个），点击后镜头会平滑飞过去聚焦，并展开该部件的说明
相机导览
底部「下一站」按钮，按预设机位依次切换视角，每个机位有一段说明
简化渲染
低性能设备可开，关掉阴影和部分细节，画面会粗糙一些但流畅

3D 首帧加载约 1~5 秒。因为要加载 three.js 运行时（1.1MB）。 加载期间会显示骨架屏，不会白屏。如果超过 10 秒还没出来，检查网络或显卡驱动。

点哪里问哪里（锚点追问）

这是整个产品最重要的交互。操作只有三步：

  1. 在画布上点你想追问的那个东西

    PPT 点某一页、2D 点某个图形、3D 点某个部件。被点中的元素会出现描边高亮。

  2. 输入框上方出现锚点标签 
    ┌──────────────────────────────────────┐
│  第 3 页 · 公民权条件           ×    │  ← 点 × 取消锚点
│  ℹ 回答将只更新该节点，其余页面不动   │
└──────────────────────────────────────┘

    输入框的提示文字也会变成「针对「第 3 页」追问…」。

  3. 输入你的问题，发送

    系统会只改这一个节点，其他内容字节级不动。版本号自动 +1。

锚点追问 vs 普通追问的区别

对比项带锚点不带锚点
检索范围锁定在该节点对应的小节全工作区范围
产物动作增量补丁（只改目标节点）可能新建一个产物
版本当前产物 +1新产物从 v1 开始
典型场景"这页拆细一点" / "这个部件叫什么""再讲讲 4.2 讲了什么"

锚点会锁定检索范围。你点了第 3 页（对应 4.1.3），问的问题只会在这个小节里找答案。 如果你想问的是别的章节，先点 × 取消锚点，否则会得到"课本未覆盖"。

为什么这个设计重要

没有锚点的话，学生说"这页讲得不清楚"，系统不知道"这页"是哪页，只能整份重新生成。 结果就是：前面调好的 5 页全丢了，学生得重新改一遍。

有锚点之后，系统知道你要改 /slides/2 这一页，只返回这一页的补丁。 响应更快（不用重新生成整份）、内容不丢、还能对比改动前后。

版本回看与对比

每次生成或补丁都会产生一个新版本，工具栏的版本下拉能看到全部历史：

项说明
版本号从 v1 开始递增。v1 是最初生成，v2 是第一次补丁，以此类推
只读预览切到历史版本时画布进入只读态，带「历史版本 v2」水印，不能追问
保留上限默认保留 20 个版本。更早的版本仍可查看，但标记为不可继续追问（patchable: false）
不可删除历史版本只能看，不能改也不能删（除非删除整个产物）

改坏了就回退。如果某次追问把某一页改得不如原来，切到上一个版本看看，记住内容后重新追问一次。 历史版本永远不会被覆盖，可以放心试。

空态是什么样

还没生成任何产物时，画布区显示三个示例问句，点一下直接填入输入框。这是给不知道怎么开始的人用的。
