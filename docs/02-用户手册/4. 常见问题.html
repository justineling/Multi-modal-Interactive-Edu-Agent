4常见问题

按「上传解析 / 回答质量 / 画布产物 / 性能显示 / 数据隐私」分类。先找到你的现象，再看原因。

上传与解析

Q：上传后一直显示"解析中"不动

先等 60 秒。113 页的教材正常 0.4 秒完成，600 页的也就几秒。超过 60 秒说明有问题。

可能原因与处理：

  • 文件特别大或页面特别复杂（大量矢量图）→ 可以点取消，拆分后重传
  • 后端进程挂了 → 看后端终端有没有报错，重启服务
  • 浏览器标签页被后台挂起 → 切回前台，轮询会恢复

Q：目录树只有「Page 1」「Page 2」这样的节点

这是章节号识别失败，系统退化成按页切分。文件卡片上会有提示。

原因通常是：教材没有规范章节号（只有标题没有编号）、章节标题是图片、或者用了非常规格式（罗马数字、纯符号）。

仍可正常提问，但失去"学习 X.X"精确锚定能力，引用粒度变粗。要修复需要扩展章节正则，属于开发者任务。

Q：同一份 PDF 能上传到不同工作区吗

可以。每个工作区独立索引，互不干扰。但同一工作区内重复上传同一份会占双份空间，检索时出现重复片段——别这么干。

Q：能上传 Word / PPT / 网页吗

目前只支持 PDF。其他格式需要先转成 PDF。

回答质量

Q：明明课本里有，为什么说"课本未覆盖"

三种可能，按概率排序：

  1. 问句里实词太少。「这个怎么理解」「为什么」这类问句，实词命中率不够门槛（45%）。 改成带上具体名词：「Malayan Union 为什么引起马来人反对」。
  2. 锚点锁定了别的小节。你点了第 3 页（4.1.3），但问的是 4.2 的内容。点 × 取消锚点再问。
  3. 教材用了不同措辞。课本写「马来亚联合邦」，你问「马来西亚联邦」——这是两个不同的东西。 换课本里的原词试试。

Q：回答里为什么没有页码

两种情况：

  • 当前是拓展模式，超纲部分本身就不该有页码（那部分不在课本里）
  • 判定为「课本未覆盖」，按设计不出现任何页码

严格模式下正常回答的每条事实陈述都必须带页码。如果没有，那是 bug。

Q：引用点开，原文跟结论对不上

这是需要反馈的问题。可能是：切片的页码映射错了、或者模型理解偏了原文。

记录三样东西：你的问句、引用的页码、展开后的原文。这属于数据质量问题，比"回答不好"更严重。

Q：为什么系统总给我 PPT，我想要 3D

系统按问句语义自动选形态。如果不满意，直接说「用 3D 展示」，会 100% 遵循你的指定。

也可以调整问法：问空间结构（"内部布局""各部分的相对位置"）更容易触发 3D，问"有哪些""几条"容易触发 PPT。

画布与产物

Q：点了 PPT 某一页，但追问后没变化

检查三件事：

  1. 输入框上方有没有锚点标签？没有的话说明没点中，再点一次页面（要看到描边高亮）
  2. 当前是不是历史版本？只读态不能追问，切回最新版本
  3. 版本号有没有 +1？如果变了但看起来一样，可能改动很小（比如只改了讲解文字）

Q：3D 场景转不动 / 白屏

  • 白屏：多半是 WebGL 不可用。检查浏览器是否禁用了硬件加速，或换 Chrome / Edge 最新版
  • 能显示但转不动：鼠标左键拖拽（不是滚轮）。触屏用单指拖
  • 很卡：开工具栏的「简化渲染」

Q：2D 动画的元素点不动

元素要在当前帧可见才能点。先把时间轴拖到它出现的那一帧。

Q：改坏了想回退

工具栏版本下拉，切到上一个版本看内容。历史版本永远保留（默认 20 个），可以放心试。

Q：能导出 PPT 文件吗

当前不支持导出 .pptx，只在页面内展示。导出功能在需求池里（P1）。

性能与显示

Q：首字要等很久

演示模式（无 API Key）下首字时间约 7 毫秒，几乎瞬时。接真实模型后取决于模型响应速度，通常 1~3 秒。

如果超过 10 秒，检查网络或模型服务状态。

Q：文字流式输出时页面卡

长对话（几十轮）时可能出现。可以新建工作区，或刷新页面（会话会从数据库恢复）。

Q：刷新页面后对话没了

应该恢复。消息会落库，刷新后自动重新加载。如果确实丢了，检查是不是切到了另一个工作区（左上角下拉）。

数据与隐私

Q：上传的教材会被传到第三方吗

取决于配置：

  • 演示模式（无 API Key）：完全本地处理，不发出任何请求
  • 接入真实模型：检索到的相关片段会随提示词发给模型服务商，不是整本教材

敏感教材建议自建模型服务（任何 OpenAI 兼容端点都支持），把 LLM_BASE_URL 指向内网。

Q：数据存在哪里

默认 SQLite 文件：backend/data/app.db。上传的原始 PDF 在 backend/data/uploads/。删掉这两个就能清空全部数据。

Q：能多人同时用吗

当前是单用户设计（没有登录体系）。多人共用需要各自开工作区，但数据在同一台服务器上。多租户在 P2 需求池。

演示模式

Q：顶栏那个黄色「演示模式」是什么

说明当前没有配置模型 API Key，系统在用内置的确定性生成器。

它的作用不是"假装有 AI"，而是让你在没有 Key 的情况下也能完整体验流程、跑通测试。 生成的 PPT / 动画 / 3D 结构是真实合法的，但内容是从检索到的课本片段里抽取重组的，不是模型理解后生成的。

Q：怎么关掉演示模式

在 backend/.env 里填上 LLM_API_KEY（以及 LLM_BASE_URL、模型名），重启后端。顶栏黄标会消失。

演示模式下的产物内容是"够用但不好看"的。它按固定模板从课本切片抽句子填充。 想看真实效果的表达力，必须接真实模型。

还是没解决？

按这个顺序排查：

  1. 看浏览器控制台（F12 → Console）有没有红色报错
  2. 看后端终端有没有异常堆栈
  3. 看 GET /api/health 是否正常
  4. 跑一遍自动化测试，确认不是环境问题：cd backend && .venv\Scripts\python.exe -m pytest tests -q
  5. 都正常的话，是产品 bug，记录完整操作步骤反馈
