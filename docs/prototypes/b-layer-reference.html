02 / 装裱并置示意

下面这一幅正是本原型要回答的观感问题：外层是 A 层的细线档案页框与框外页眉页脚， 内层是一页抽象彩色课件。判断「档案外壳 + 彩色内页」是否成立，看这一幅即可。

FILE X-003 DOC-001
SOURCE / [p.94] 01/05

档案外壳负责第几份、第几页、出自哪里，彩色课件页负责这一页教什么； 如同纸质卷宗里夹着一页彩色插图，装帧语言与原件内容各司其职，不互相染色。 统一感来自同一根 1px 细线、同一套编号、同一条对齐线，而不是同一套颜色。

诚实提示（勿据此页低估真实反差）：本页内页底色用的是 PALETTE 的浅底 #E2E8F0，仅为抽象示意。真实 SlideRenderer 的画布底色是 #F8FAFC、布局卡片是 #FFFFFF（亮色）或 #0B1220（暗色）， 即一页接近纯白的高饱和画面夹在暖灰纸 #eae5e1 里，接缝会比本页更明显。 此外本原型按 Q-5 默认亮色，而生产 theme.ts 当前以深色为主 —— 全量推进前需就 「深色外壳 + 白色课件页」再拍一次板。
