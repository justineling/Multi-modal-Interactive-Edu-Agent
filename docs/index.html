上面 21 篇是系统级文档，随代码长期有效。这一组是一次具体改造的过程记录—— 包括需求、设计、实测数据、被数据否掉的方案、以及 QA 的独立验证。

项目一句话说明

传统 AI 助教是「聊天框 + 一段文字」。这个项目的核心判断是：纯文字讲不清结构和过程。 历史课本里的疆域变迁、物理里的受力分解、生物里的代谢流程，文字描述再多也不如一张会动的图。

所以它把回答形态扩展成三种：PPT（离散有序的知识点）、2D 动画（随时间演变的过程）、 3D 场景（需要空间想象的结构）。而且这三种产物都是「活的」——你能点进去追问，系统只改那一处。

如果你是第一次接触这个项目，建议顺序：
① 这个项目是什么 → ② 环境搭建与运行 → ③ 一次提问的完整旅程。 走完这三篇，你对整个系统的理解会超过读十篇零散笔记。

技术栈速查

层选型
前端React 19 · TypeScript · Vite 7 · TailwindCSS 3.4 · Zustand · Allotment
PPT 渲染自定义 JSON 渲染器（6 种教学布局）+ Framer Motion

版本锁定是硬约束，不是建议。 @react-three/fiber 必须 v9（v8 与 React 19 不兼容，装了整块 3D 画布白屏）、 react-konva 必须 19、tailwindcss 必须 v3.4（v4 是 CSS-first 配置，写法完全不同）、 katex 必须 0.16 线（装 0.19 会出现两份 katex 导致公式字体错位）。
