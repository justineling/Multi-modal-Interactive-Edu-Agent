产品目标与非目标

三个正交目标

编号目标怎么算达成
G1严格锚定教材每条事实陈述可追溯到课本页码；无覆盖时明确拒绝而非编造
G2多形态具象化按知识点属性自动选 PPT / 2D / 3D，用户可覆盖
G3上下文连续迭代点画布任意节点追问，只改那一处，历史版本可回看

与聊天机器人的三条红线

  • 不做通用问答。课本没有的就明确说没有，不靠模型内建知识兜底（除非用户主动切拓展模式）。
  • 不做纯文字输出。每次回答必须考虑"该用什么形态呈现"。
  • 不做一次性生成。产物必须可被局部修改，不能"重做一遍"。

为什么 P0-07/08/09 是"部分通过"而不是"通过"？ 它们的验收标准里有一半是前端行为（6 种布局渲染、拖时间轴 60 次不掉帧、3D 轨道旋转）。 后端只能验 spec 结构正确、页码标注正确、不含注入。 这部分需要真实浏览器 + 人工观察，不在自动化范围内——这是诚实的边界，不是逃避。

编号风险缓解
